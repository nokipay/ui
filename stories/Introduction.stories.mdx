# 🎨 NxPay UI Library

Bienvenue dans la bibliothèque de composants **NxPay UI** !

## 🌈 Design System

NxPay utilise une palette de **5 couleurs** harmonieuses formant un gradient du **vert au violet** :

1. **Vert Clair** - `#77F07F` (Primary)
2. **Teal** - `#3FC995` (Secondary)
3. **Bleu Turquoise** - `#40A0AE` (Tertiary)
4. **Bleu Moyen** - `#37669C` (Quaternary)
5. **Violet Foncé** - `#3A2F6B` (Accent)

### Gradient Signature

```css
background: linear-gradient(135deg, #77F07F 0%, #3FC995 50%, #40A0AE 100%);
```

## 📦 Installation

```bash
pnpm add @nxpay/ui
```

## 🚀 Quick Start

```vue
<template>
  <NokiButton color="primary" label="Click me" />
</template>
```
