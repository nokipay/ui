# Design Tokens NxPay

Documentation complète des design tokens disponibles dans NxPay UI.

---

## Colors

### Couleurs Principales

```typescript
import { colors } from '@nxpay/ui/utils/designTokens'

colors.nxGreen          // '#77F07F'
colors.nxTeal           // '#3FC995'
colors.nxBlueTurquoise  // '#40A0AE'
colors.nxBlue           // '#37669C'
colors.nxPurple         // '#3A2F6B'
```

### Couleurs Sémantiques

```typescript
colors.success          // '#77F07F' (Vert)
colors.warning          // '#f59e0b'
colors.error            // '#ef4444'
colors.info             // '#40A0AE' (Bleu Turquoise)
```

### Couleurs Neutres

```typescript
colors.white            // '#ffffff'
colors.black            // '#000000'
colors.gray[50]         // '#f9fafb'
colors.gray[500]        // '#6b7280'
colors.gray[900]        // '#111827'
```

## Gradients

```typescript
import { gradients } from '@nxpay/ui/utils/designTokens'

gradients.primary       // Gradient signature
gradients.vertical      // Gradient vertical
gradients.horizontal    // Gradient horizontal
gradients.button        // Pour boutons
gradients.card          // Pour cards
```

### Gradient Signature

```css
background: linear-gradient(135deg, #77F07F 0%, #3FC995 50%, #40A0AE 100%);
```

## Shadows

```typescript
import { shadows } from '@nxpay/ui/utils/designTokens'

shadows.sm       // Standard small
shadows.md       // Standard medium
shadows.lg       // Standard large
shadows.xl       // Standard extra large
shadows['2xl']   // Standard 2xl

// Shadows avec couleurs NxPay
shadows.nxGreen  // '0 4px 14px 0 rgba(119, 240, 127, 0.39)'
shadows.nxTeal   // '0 4px 14px 0 rgba(63, 201, 149, 0.39)'

// Glassmorphism
shadows.glass    // '0 8px 32px 0 rgba(31, 38, 135, 0.37)'
```
