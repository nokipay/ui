## 🎯 Liens Rapides

### Installation & Démarrage

```bash
# Installer
pnpm install

# Développement
pnpm dev              # Playground (port 3000)
pnpm storybook        # Storybook (port 6006)

# Tests
pnpm test             # Tests unitaires
pnpm test:coverage    # Avec coverage

# Build
pnpm build            # Build module
```
